# FitForge Gym Website 🏋️
### Designed & Developed by Sk Kutubuddin

A premium React-based gym website with modern animations, dark yellow theme, and elite UI/UX.

---

## 🚀 Features

- ✅ Smooth scroll navigation
- ✅ Hero section with background video
- ✅ Scroll-triggered animations (reveal on scroll up/down)
- ✅ Custom cursor with follower
- ✅ Animated stat counters
- ✅ Pricing toggle (Monthly/Yearly)
- ✅ Gallery with lightbox
- ✅ Contact form
- ✅ Mobile-responsive (all breakpoints)
- ✅ Developer portfolio section
- ✅ Dark + Yellow color theme
- ✅ Modern fonts (Bebas Neue + Barlow)

## 🛠️ Installation & Run

```bash
# 1. Go into project folder
cd gym-website

# 2. Install dependencies
npm install

# 3. Start development server
npm start

# 4. Build for production
npm run build
```
